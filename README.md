# Project Overview

The Gaming Room is expanding its existing game, "Draw It or Lose It", from a mobile Android app to a web-based application. My goal with this project was to design a solution that enhances scalability, accessibility, and user experience while maintaining robust system performance and security.

### Software Requirements

* Support for multiple teams and players per game

* Enforce unique game, team, and player names

* Ensure only one game instance exists in memory at a time

* Prioritize scalability, security, and cross-platform compatibility

### What I Did Well

I belive one of my strengths in developing this documentation was structuring the design in a clear and logical manner, or at least I really tried to. I focused on object-oriented principles like encapsulation, inheritance, and design patterns such as Singleton and Iterator. I also thoroughly evaluated different operating platforms and provided recommendations for infrastructure and deployment, ensuring a well-rounded approach.

### How the Design Document Helped

Working through this document before jumping into development helped me establish a clear system structure and reduced ambiguity in coding. By considering constraints like concurrency, scalability, and memory management early on, I was able to streamline development and create a strong technical foundation.

### What I Would Improve

If I were to revise and redo this document, I would add more detailed system architecture diagrams to illustrate request handling and data flow. Additionally, expanding the security section to include a risk assessment and mitigation strategies would provide a more comprehensive view of potential challenges and solutions.

### Understanding and Implementing User Needs

Throughout this project, I focused on making sure the software met the user’s needs. I prioritized real-time gameplay, intuitive team management, and secure authentication. By ensuring accessibility across multiple platforms, I aimed to create a seamless and engaging experience for players.

### My Approach to Software Design

* Applied object-oriented principles to ensure modularity and maintainability

* Designed a web-based architecture for maximum accessibility

* Used RESTful APIs and WebSockets for efficient communication

* Combined relational (MySQL/PostgreSQL) and NoSQL (Redis) databases for optimized performance

### Future Strategies

Looking ahead, I plan to:

* Implement DevOps best practices for continuous integration and deployment

* Strengthen security measures to protect user data

### Conclusion

This project has been a very valuable learning experience, reinforcing my understanding of software design principles while allowing me to create a scalable and secure solution. The completed design document effectively communicates the project’s technical and functional requirements, making it a strong addition to my portfolio.
